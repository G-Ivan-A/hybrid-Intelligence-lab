# Аудит бэклога Хаба после выносов (PR #739, #743)

## Summary / BLUF

Бэклог на `main@24cd7ff` отставал от фактов в двух местах. Первое — вынос
метамодели БА: этапы E1–E6 слиты в `ba-ai-metamodel` (PR #2–#7, `e1f67e2`),
а B-244…B-247 стояли в `TODO`. Второе — вынос `aether-orbis-proxeneta`:
владелец принял импорт и подтвердил PRIVATE, а B-309 и B-310 стояли в
`ЧАСТИЧНО`. Статусы исправлены по проверяемым источникам.

Отдельно найдены три строки, которые противоречат правилу RFC #715 о
принадлежности BA-строк спице (B-264…B-266). Аудит вынес их отмену на решение
владельца; по [решение владельца в PR #746](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/pull/746#issuecomment-6977571960) они переведены в `CANCELLED`
как потерявшие актуальность для Хаба.

Блокер тарифа снят. 2026-11-17 защиту тегов `archive/*` (Q-6, B-281) нельзя
было включить: Хаб был приватным, и GitHub отвечал HTTP 403 «Upgrade to GitHub
Pro or make this repository public». По решению владельца Хаб переведён в
Public, API rulesets отвечает без ошибки, и инструкция `archive-tag` об импорте
эталона снова исполнима. Временная ветка workflow про тариф удалена. Остаётся
одно действие администратора: импортировать ruleset (B-281).

Задачи финальной очистки Хаба существуют. Для метамодели БА надгробие,
ссылки и снятие заморозки выполнены в PR #745 (B-249 `ЧАСТИЧНО`: остаток —
`mango_ba_prompts#488`); B-248 `DONE` после слияния runtime PR #24; триггер
замера B-250 сработал. Для proxeneta очистка выполнена в PR #743. Для всех
трёх выносов остаётся один общий ruleset `archive/*` (B-281). Новых задач аудит
не создаёт.

Вопросы аудита закрыты вторым решением владельца ([решение владельца в PR #746 от 2026-11-18 (2)](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/pull/746#issuecomment-6988585725)). B-308 `DONE`:
остаточная публичность ранее опубликованной истории proxeneta принята, история
не переписывается; Спринт 33 закрыт и подлежит архивации (B-260). B-310
остаётся `DONE`, защита тегов учитывается один раз — в B-281. Импорт ruleset
(B-281) владелец отложил и выполнит сам; до него красный `archive-tag` на `main`
— ожидаемое состояние. Остаток B-249 (#488) и замер B-250 открыты.
