# Антипаттерны синхронизации `AGENTS.md`

| Антипаттерн | Наблюдаемый признак | Правильное действие |
| --- | --- | --- |
| Слепое копирование | Hub-файл перенесён byte-for-byte, а archetype, пути или project rules неверны. | Сравнить по слоям и адаптировать только разрешённые секции. |
| Среда/adapter «на всякий случай» | GigaCode rules есть без значения профиля или Cursor/Copilot adapter без явного scope. | Runtime delta брать из профиля; model adapter — из bootstrap/task scope. |
| Второй SSOT | `CLAUDE.md`, Copilot/Cursor/GigaCode файл повторяет нормативный текст. | Сгенерировать короткий pointer/import на `/AGENTS.md` и защитить от drift. |
| Ручной fork general layer | Проект исправляет общую норму только у себя. | Предложить изменение в Hub; до принятия сохранить норму и эскалировать конфликт. |
| Необоснованное project rule | Правило появилось из одной задачи, привычки агента или отсутствующего пути. | Сослаться на принятый concept/contract либо записать gap. |
| Непроверяемый `derived_from` | Указана ветка `main`, дата или свободный текст без commit SHA. | Записать точный upstream commit в предусмотренном B-111 поле/манифесте. |
| Перезапись локальной работы | Скрипт заменяет проектный файл при локальной дельте. | Fail closed, показать diff и потребовать явное разрешение в PR. |
| Нет проверки изоляции | После синхронизации не запущены project validators/EP-C1. | Проверить структуру, ссылки, placeholders, adapters и локальные тесты. |
| «Зелёный» через удаление нормы | Для прохождения size/check правило сокращено или удалено. | Выделить субконтракт в canonical home и оставить route. |

## Критерий отказа

Если архетип, primary environment, источник локального правила или судьба
конфликтующей нормы не подтверждены активным контрактом, синхронизация не
угадывает ответ. Исполнитель завершает независимую часть, а вопрос с вариантами
и рекомендацией помещает в тело PR.
