# Синхронизация `AGENTS.md` в проектах экосистемы

Этот каталог — операционный вход для ручной синхронизации корневого
`AGENTS.md` Хаба в отдельный репозиторий. Он не создаёт ещё один стандарт:
инварианты задают
[стандарт бутстрапа](../../standards/agents-md-bootstrap-standard.md) и
[ADR-012](../../docs/adr/2026-09-adr-012-agents-md-root-contract.md), а здесь
описано, как применить их к конкретному проекту без слепого копирования.

## Когда запускать

Синхронизацию инициирует пользователь отдельной задачей:

- при первой доставке `AGENTS.md`;
- после изменения general layer или обязательных секций в Хабе;
- после изменения `.hub-profile.json`, среды или проектного concept;
- когда check-режим B-111 обнаружил дрейф.

Автоматический merge или фоновое переписывание spoke не допускаются. Скрипт
B-111 может подготовить и проверить дельту, но решение о проектной адаптации и
merge остаётся в PR целевого репозитория.

## Маршрут

1. Создать задачу по [шаблону](templates/sync-agents-md-task.md).
2. Выполнить preflight и классификацию по
   [правилам синхронизации](synchronization-rules.md).
3. Проверить [антипаттерны](anti-patterns.md) и условия включения адаптеров
   [конкретной среды](environment-specific.md).
4. Сформировать проектный файл на основе
   [структурного шаблона](templates/project-agents-md-template.md), сохранив
   содержимое general layer из актуального шаблона нужного архетипа.
5. Запустить локальные валидаторы проекта и check-режим B-111; приложить отчёт о
   дельте к PR.
6. После human review и merge записать upstream commit и дату синхронизации в
   профиль проекта, когда такие поля будут реализованы B-111.

## Граница с B-111

Этот каталог отвечает на вопрос «что адаптировать и как проверить». B-111
реализует безопасную механику: dry-run по умолчанию, отчёт о дельте, защита от
локальных правок и check-режим. Скрипт не определяет архетип, среду или
проектные правила вместо профиля и владельца проекта.
