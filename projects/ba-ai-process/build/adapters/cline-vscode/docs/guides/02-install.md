## Что установить и зачем

| Программа | Зачем |
|-----------|-------|
| [VS Code](https://code.visualstudio.com/download) | Редактор, в котором вы открываете пакет и работаете |
| [Cline](https://docs.cline.bot/getting-started/installing-cline) | Расширение VS Code — ИИ-помощник |
| [Git](https://git-scm.com/download/win) | Скачивание пакета и KB, отправка результатов |
| [Python 3.11+](https://www.python.org/downloads/windows/) | Нужен runner и hooks. Дополнительные библиотеки **не нужны** — используется только стандартная библиотека Python |

Если на АРМ нет прав администратора, попросите администратора установить
программы из корпоративного каталога ПО.

## Установка на Windows 10/11 x64

1. **VS Code.** Скачайте «Windows x64 User Installer», запустите. На шаге
   «Дополнительные задачи» отметьте «Добавить в PATH».
2. **Git.** Скачайте «64-bit Git for Windows Setup», установите с настройками
   по умолчанию.
3. **Python.** Скачайте «Windows installer (64-bit)» версии 3.11 или новее.
   На первом экране **обязательно** отметьте **Add python.exe to PATH**, затем
   нажмите Install Now.
4. **Cline.** Откройте VS Code → слева значок Extensions (`Ctrl+Shift+X`) →
   найдите **Cline** (издатель — Cline, официальное расширение) → Install.
   Слева появится значок Cline.
5. Закройте и снова откройте VS Code, чтобы он увидел новые программы.

> Для macOS/Linux: установите те же программы штатными средствами ОС;
> в командах ниже вместо `python` используйте `python3`.

## Подключение модели в Cline

Зачем: Cline сам по себе не содержит модель, он обращается к серверу Mango AI.

1. Откройте панель Cline → значок настроек (шестерёнка).
2. API Provider: **OpenAI Compatible**.
3. Base URL — выданный администратором AI Core.
4. API Key — ваш личный ключ `sk-…`.
5. Model ID: `gpu-default`.
6. Context Window: `114688`; Max Output Tokens: `16384`.
7. Поддержку изображений (Supports Images) — выключить.
8. Сохраните. Для доступа к серверу может понадобиться VPN.

Ключ хранится только здесь. Не вставляйте его в чат, файлы и снимки экрана.

## Проверка установки

Откройте в VS Code терминал: меню **Terminal → New Terminal**
(`Ctrl+``). По умолчанию это PowerShell. Выполните по одной команде:

```powershell
code --version
git --version
python --version
```

| Команда | Признак успеха |
|---------|----------------|
| `code --version` | Номер версии VS Code, например `1.9x.x`, и строка `x64` |
| `git --version` | `git version 2.x.x.windows.x` |
| `python --version` | `Python 3.11.x` или новее (3.12, 3.13 …) |

Проверка Cline без запуска задачи: откройте панель Cline и напишите
`Ответь одним словом: готов`. Пришёл ответ — связь с моделью есть.
Это не задача: файлы не создаются и не меняются.

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| `python` не найден или открывается Microsoft Store | Переустановите Python с галочкой **Add python.exe to PATH**; либо используйте `py -3` вместо `python` во всех командах; перезапустите VS Code |
| `Python 3.10` или старше | Установите 3.11+ |
| `code`/`git` не найден | Перезапустите VS Code; если не помогло — переустановите с добавлением в PATH |
| Cline отвечает ошибкой 401/403 | Проверьте ключ; обратитесь к администратору AI Core |
| Cline не отвечает / таймаут | Включите VPN, проверьте Base URL |
| Скрипты PowerShell запрещены политикой | Команды этой инструкции не требуют `.ps1`-скриптов; если ошибка всё же появилась — обратитесь к администратору |

Готово, если все три команды показали версии и Cline ответил.
Переходите к [развёртыванию пакета](03-deploy-package.md).
