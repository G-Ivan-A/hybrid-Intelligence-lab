# 1. Установка ПО на АРМ и проверка

**Цель:** установить нужные программы, подключить модель и убедиться, что
всё работает. Задачи на этом шаге не запускаются, файлы пакета не нужны.

## Что установить и зачем

| Программа | Зачем | Что ставить дополнительно |
|-----------|-------|---------------------------|
| [Windows Terminal](https://learn.microsoft.com/windows/terminal/install) | [Терминал](01-junior-pilot.md#term-terminal) с вкладками: в одной работает OpenCode, в другой вы вводите команды | Ничего. В Windows 11 он уже есть; в Windows 10 — из Microsoft Store или корпоративного каталога ПО |
| [Git](https://git-scm.com/download/win) | Скачать пакет и базу знаний; при необходимости отправить результат | Ничего. На АРМ компании Git уже установлен |
| [Python 3.11 или новее](https://www.python.org/downloads/windows/) | На Python написаны [runner](01-junior-pilot.md#term-runner), проверки пакета и [плагин защиты](01-junior-pilot.md#term-guard-plugin) | **Ничего.** Используется только стандартная библиотека Python. Команду `pip install` выполнять не нужно |
| [Node.js LTS](https://nodejs.org/en/download) | Нужен, чтобы установить OpenCode через `npm` | Ничего |
| [OpenCode 1.18.35](https://opencode.ai/docs/) | ИИ-агент в терминале, с которым вы ведёте диалог | Пакет проверен именно на версии 1.18.35 |

Если на АРМ нет прав администратора, попросите администратора установить
программы из корпоративного каталога ПО.

Документация OpenCode рекомендует для Windows подсистему WSL
([страница](https://opencode.ai/docs/windows-wsl/)). В пилоте WSL **не**
используется: OpenCode ставится напрямую в Windows, как описано ниже, и
работает в Windows PowerShell.

## Установка на Windows 10/11 x64

1. **Windows Terminal.** Проверьте, что в меню «Пуск» есть «Терминал»
   (Windows Terminal). Если нет — установите его. Без него можно работать в
   двух окнах **Windows PowerShell**, но с вкладками удобнее.
2. **Git.** Если Git уже установлен на АРМ, повторно ставить его не нужно.
   Иначе скачайте «64-bit Git for Windows Setup» и установите с настройками
   по умолчанию.
3. **Python.** Скачайте «Windows installer (64-bit)» версии 3.11 или новее.
   На первом экране **обязательно** отметьте **Add python.exe to PATH**, затем
   нажмите **Install Now**.
4. **Node.js.** Скачайте «Windows Installer (.msi)» версии **LTS** для x64 и
   установите с настройками по умолчанию.
5. Закройте все окна терминала и откройте терминал заново, чтобы он увидел
   новые программы.
6. **OpenCode 1.18.35.**
   - **Где:** терминал (PowerShell), папка не важна.
   - **Команда:**

     ```powershell
     npm install -g opencode-ai@1.18.35
     ```

   - **Что делает:** скачивает OpenCode из реестра npm и устанавливает его
     для вашей учётной записи.
   - **Ожидаемый результат:** строка вида `added 1 package` (число может
     отличаться) и новая строка приглашения `PS …>`.
   - **Проверьте:** нет строк `ERR!`. Если есть — см.
     [Если что-то не так](#если-что-то-не-так).
7. Закройте и откройте терминал ещё раз.

Другие способы установки (`choco install opencode`, `scoop install opencode`)
описаны в [документации OpenCode](https://opencode.ai/docs/); для пилота
используйте `npm` с номером версии, чтобы версия совпадала у всех.

## Подключение модели в OpenCode

Зачем: OpenCode сам по себе не содержит модель — он обращается к серверу
Mango AI ([модель](01-junior-pilot.md#term-model)). Подключение состоит из
двух частей: **описание провайдера** в глобальном файле настроек OpenCode
и **API-ключ** в хранилище учётных данных OpenCode. Обе части хранятся
только на вашем АРМ, вне папки пакета.

### Опишите провайдера Mango AI

- **Где:** терминал (PowerShell).
- **Команда:**

  ```powershell
  New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\opencode"
  notepad "$env:USERPROFILE\.config\opencode\opencode.json"
  ```

- **Что делает:** создаёт папку глобальных настроек OpenCode и открывает
  файл настроек в Блокноте. На вопрос «Создать новый файл?» ответьте **Да**.
- Вставьте в Блокнот текст ниже, замените `<Base URL>` на адрес от
  администратора AI Core (кавычки оставьте), сохраните (`Ctrl+S`) и закройте
  Блокнот:

  ```json
  {
    "$schema": "https://opencode.ai/config.json",
    "provider": {
      "mango": {
        "npm": "@ai-sdk/openai-compatible",
        "name": "Mango AI",
        "options": {
          "baseURL": "<Base URL>"
        },
        "models": {
          "gpu-default": {
            "name": "gpu-default",
            "limit": {
              "context": 114688,
              "output": 16384
            }
          }
        }
      }
    },
    "model": "mango/gpu-default"
  }
  ```

- **Проверьте:** в файле нет ключа `sk-…`. Ключ сюда **не** пишется.

Подробнее о формате — [Providers](https://opencode.ai/docs/providers/) в
документации OpenCode.

### Сохраните API-ключ

- **Где:** терминал (PowerShell).
- **Команда:**

  ```powershell
  opencode auth login
  ```

- **Что делает:** открывает диалог сохранения учётных данных.
- **Действия в диалоге:**
  1. В списке провайдеров выберите стрелками **Other** и нажмите Enter
     (можно начать печатать `other` для поиска).
  2. **Enter provider id:** введите `mango` и нажмите Enter.
  3. OpenCode напомнит, что провайдер нужно описать в `opencode.json` — это
     вы уже сделали.
  4. **Enter your API key:** вставьте ключ `sk-…` и нажмите Enter. Символы
     ключа на экране не отображаются.
- **Ожидаемый результат:** сообщение `Done` и строка приглашения `PS …>`.
- **Проверьте:** ключ не попал ни в один файл пакета и ни в один снимок
  экрана.

Ключ хранится в файле `auth.json` в профиле пользователя (путь показывает
команда `opencode auth list`). Не вставляйте ключ в чат, файлы пакета,
снимки экрана. Чтобы заменить ключ, повторите `opencode auth login`;
чтобы удалить — `opencode auth logout`.

Другие модели (например, DeepSeek) подключить технически можно — см.
[Внешняя модель](06-working-with-opencode.md#можно-ли-подключить-внешнюю-модель-например-deepseek).
Для пилота используйте модель Mango AI.

## Проверка установки

### Проверить версии программ

- **Где:** терминал (PowerShell). Папка пока не важна.
- **Команды** — по одной, после каждой нажмите Enter:

  ```powershell
  git --version
  python --version
  node --version
  opencode --version
  ```

- **Ожидаемый результат:**

  | Команда | Что должно появиться |
  |---------|----------------------|
  | `git --version` | `git version 2.x.x.windows.x` |
  | `python --version` | `Python 3.11.x` или новее (3.12, 3.13 …) |
  | `node --version` | `v22.x.x` или новее (номер версии LTS) |
  | `opencode --version` | `1.18.35` |

- **Проверьте:** ни одна команда не ответила «не является именем командлета»
  (`is not recognized`) или «выполнение сценариев отключено».

### Проверить подключение модели

- **Где:** терминал (PowerShell).
- **Команды:**

  ```powershell
  opencode auth list
  opencode models mango
  ```

- **Ожидаемый результат:** первая команда показывает строку с `mango` и
  типом `api`; вторая — строку `mango/gpu-default`.
- **Проверьте:** если `opencode models mango` ничего не вывела, провайдер
  не описан: проверьте путь командой `opencode debug paths` (строка
  `config` — папка, в которой должен лежать `opencode.json`) и текст файла.

### Проверить связь с моделью

- **Где:** терминал (PowerShell).
- **Команда:**

  ```powershell
  opencode run "Ответь одним словом: готов"
  ```

- **Что делает:** один раз обращается к модели без открытия окна OpenCode.
  Команда выполняется в текущей папке; файлы при этом не создаются и не
  меняются: это не задача, а проверка связи.
- **Ожидаемый результат:** ответ модели, например `Готов`.
- **Проверьте:** нет сообщения об ошибке 401/403, `Model not found` или
  таймауте.

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| `python` не найден или открывается Microsoft Store | Переустановите Python с галочкой **Add python.exe to PATH** и откройте терминал заново. Плагин защиты пробует `python`, затем `py -3`; в командах терминала можно использовать `py -3` вместо `python` |
| `Python 3.10` или старше | Установите 3.11 или новее |
| `npm` или `opencode`: «выполнение сценариев отключено в этой системе» | Политика PowerShell запрещает файлы `.ps1`. Набирайте `npm.cmd` вместо `npm` и `opencode.cmd` вместо `opencode`. Не меняйте системную политику исполнения самостоятельно; при необходимости передайте текст администратору |
| `npm install` отвечает `ETIMEDOUT`, `ECONNRESET`, `407` или `self-signed certificate` | Нужен корпоративный прокси или сертификат. Передайте текст ошибки администратору: он настроит `npm config set proxy …` / `cafile` |
| `opencode --version` показывает другой номер | Повторите `npm install -g opencode-ai@1.18.35` |
| `opencode` не найден после установки | Закройте и откройте терминал. Если не помогло — выполните `npm prefix -g` и попросите администратора добавить эту папку в PATH |
| `opencode models mango` ничего не выводит | Файл настроек лежит не там или в нём ошибка: проверьте путь по `opencode debug paths` и сверьте текст с образцом |
| Ответ модели — ошибка 401/403 | Проверьте ключ (`opencode auth login` ещё раз); обратитесь к администратору AI Core |
| Модель не отвечает / таймаут | Включите VPN, проверьте Base URL |

**Готово**, если все четыре команды показали версии, `opencode models mango`
показала `mango/gpu-default` и модель ответила. Переходите к
[развёртыванию пакета](03-deploy-package.md).
