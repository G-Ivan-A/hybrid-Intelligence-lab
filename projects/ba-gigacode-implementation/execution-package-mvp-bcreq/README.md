# Пакет исполнения MVP BCREQ

Компиляция вертикального среза `A-IN → A-CORE → A-BCREQ` для продуктового
класса «контакт-центр» в форму, разворачиваемую в чистый репозиторий-спутник
(`mango-ba-ai-runtime`) копированием каталога.

Пакет — **артефакт компиляции**, а не ещё один исследовательский модуль:
исследовательские тексты в нём не дублируются, их нормативные следствия
перенесены в навыки, схемы и правила. Состав того, что скопировано,
преобразовано и отброшено, объявлен в `compilation-manifest.yaml`.

## Состав

| Каталог | Содержание |
| --- | --- |
| `taxonomy/` | закрытые машиночитаемые словари: артефакты, процессы, операции, продукты, уровни источников, проекции, термины домена |
| `contracts/` | `C-IN`, `C-CORE`, `C-CL`, `C-OUT`, `C-RK` как JSON Schema |
| `routes/` | граф маршрута `RG-BCREQ-v1` и шаблон листа прогона |
| `.agents/skills/` | 11 `SKILL.md` узлов маршрута с полями GigaCode `name` и `description` |
| `templates/` | скелеты `A-BCREQ`, `A-QUEST`, `A-CORE` |
| `golden/` | два положительных эталона, четыре отрицательных и машиночитаемый индекс |
| `evaluation/` | метрики `M-1…M-5`, `MP-1…MP-6` и чек-листы гейтов |
| `tools/` | `validate-package.py` — машинный гейт `G-mach` |
| `AGENTS.md` | загрузочный контракт агента в спутнике с исполняемыми правилами |

## Как развернуть

```sh
cp -R projects/ba-gigacode-implementation/execution-package-mvp-bcreq/. <spoke-repo>/
cd <spoke-repo> && pip install pyyaml && python3 tools/validate-package.py
```

Спутник может жить там, где доступа к репозиторию модели нет. Поэтому пакет
содержит физические копии, а не ссылки: ни один артефакт времени выполнения не
ссылается наружу, и это проверяется машинно.

## Как проверить

```sh
python3 tools/validate-package.py projects/ba-gigacode-implementation/execution-package-mvp-bcreq
```

Валидатор проверяет закрытость словарей, формат идентификаторов операций,
разрешимость каждого узла графа в скомпилированный навык, достижимость узлов и
непустые предикаты рёбер, шесть обязательных разделов каждого `SKILL.md`,
полноту слотов в эталонах, полноту перечня метрик и отсутствие ссылок наружу.
Дополнительно проверяются три контракта, до этого существовавшие только
текстом: маршрутизация источников (уровень обязателен во входе и разрешим в
словарь), проекция документа (обязательна в выходе и разрешима в словарь) и
`EP-G7` — каждая пара близких терминов словаря домена покрыта отрицательным
случаем Golden Set.

## Отклонение от постановки

Постановка относит к `P-01` три навыка; сборка `A-CORE` при этом остаётся без
исполнителя. Скомпилировано 11 навыков: `P-01` — четыре (добавлен
`core-assembly-contact-center`), `P-02` — три, `P-03` — четыре. Расхождение
вынесено в бэклог как задача согласования таксономии процессов.

## Источник истины

Развивающаяся модель живёт в этом репозитории. Правка нормативного содержания в
спутнике — дефект процесса: наблюдение из прогона возвращается задачей сюда,
после чего пакет компилируется заново со сменой `hub_commit` и `compiled_at`.
