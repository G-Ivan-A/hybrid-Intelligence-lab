# Чек-лист машинного гейта G-mach

Гейт `fail-closed`: непройденная проверка **останавливает** маршрут, а не
помечает артефакт предупреждением. Порядок гейтов всегда
`G-self → G-mach → G-human`: человек не тратится на то, что ловит валидатор.

Каждая проверка ниже исполняется скриптом `tools/validate-package.py` либо
скриптом прогона; ни одна не требует суждения о смысле.

| № | Проверка | Основание отказа |
| --- | --- | --- |
| 1 | Вход прогона проходит `contracts/c-in.schema.json` | вход без объявленного продукта, задачи или источника |
| 2 | Ядро проходит `contracts/c-core.schema.json` | элемент без ссылки на источник |
| 3 | Документ проходит `contracts/c-out-bcreq.schema.json` | отсутствует слот скелета |
| 4 | Каждый пустой слот несёт причину из закрытого перечня | «нет по продукту» неотличимо от «забыли» |
| 5 | Раздел `S-OTHER` в документе отсутствует | незавершённая разметка |
| 6 | Подпись слота каноническая, без союза «и», соединяющего два слота | два слота одним разделом |
| 7 | Класс формата не `F-MIXED` | незавершённый переход между классами |
| 8 | Каждая цитата дословно присутствует в своём источнике | недоказуемое утверждение |
| 9 | Каждое требование `S-FR` встречается в `S-TRACE` | разрыв следа |
| 10 | Лист прогона содержит все поля `trace.required` | прогон не принимается и в метриках не участвует |
| 11 | Значение `process` каждого шага принадлежит `taxonomy/processes.yaml` | возврат к свободному тексту |
| 12 | Скелет выхода совпадает со скелетом эталона его класса | структурное расхождение с Golden Set |
| 13 | Для негативного случая зафиксирован ожидаемый отказ | «исправление по смыслу» вместо остановки |
| 14 | Число корректирующих попыток узла не превышает одной | третий автоматический запуск запрещён |

Расхождение с эталоном **по содержанию** отказом не является: иначе прогон
воспроизводит эталон вместо решения задачи.
