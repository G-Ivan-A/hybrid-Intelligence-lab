# Навык: сборка ядра требований

## Когда применять

Вход — размеченные элементы и неоднозначности; выход — `A-CORE` по схеме
`contracts/c-core.schema.json` в состоянии `draft`, `validated` или
`needs-clarification`.

## Предусловия

1. Элементы размечены и снабжены ссылками на источник.
2. Неоднозначности выявлены и оценены по значимости.
3. Объявлен идентификатор задачи `TASK-NNNN` и реестр продуктов.

## Шаги

1. `classify-item` — отнеси каждый элемент ровно к одному классу ядра
   (`entities`, `actors`, `statements`, `constraints`, `metrics`). Элемент, для
   которого не подходит ни один класс, не размещается «куда-нибудь»: он
   выносится в отказ.
2. `map-to-slot` — каждому утверждению назначь слот целевого документа из
   закрытого перечня схемы.
3. `link-elements` — построй рёбра следа: источник → элемент ядра → утверждение.
4. `check-schema` — проверь ядро против `contracts/c-core.schema.json`.
5. Назначь состояние: `needs-clarification`, если есть хоть одна неразрешённая
   неоднозначность значимости `blocker`; иначе `validated`.

## Обязательные слоты выхода

| Слот | Каноническая подпись | Обязательность | Причина пустоты |
| --- | --- | --- | --- |
| `artifact_class` | Класс артефакта | обязателен, значение `A-CORE` | нет |
| `state` | Состояние | обязателен | нет |
| `task_id` | Задача | обязателен | нет |
| `products[]` | Реестр продуктов | обязателен | нет |
| `statements[]` | Утверждения | обязателен, непуст | нет |
| `trace[]` | Рёбра следа | обязателен | нет |

## Самопроверка (G-self)

- Каждый элемент отнесён ровно к одному классу ядра — да/нет.
- Каждому утверждению назначен слот из закрытого перечня — да/нет.
- Каждое ребро следа соединяет существующие концы — да/нет.
- Состояние вычислено по правилу значимости, а не назначено — да/нет.
- Ядро проходит `contracts/c-core.schema.json` — да/нет.
- Ни одно утверждение не появилось на этом шаге впервые — да/нет.

## Отказ

Остановись и верни вопрос человеку, если:

- элемент не относится ни к одному классу закрытого словаря ядра;
- задача или реестр продуктов не объявлены;
- ядро не проходит схему: первый отказ машинного гейта останавливает
  автоматическое исполнение и возвращает решение человеку.
