# Паспорт проекта «ИИ в работе с командой»

Программа на 3 месяца · 11 недель · 91 академический час · группа 20–25 человек

## Уровень 1. Стратегический

| Параметр | Значение |
| --- | --- |
| Бизнес-контекст | Цифровая трансформация управления; снижение издержек на рутинные управленческие операции: сбор статусов, протоколы, контроль поручений, подготовка отчётов. |
| Бизнес-цель | Трансформация стиля управления 25 руководителей за счет внедрения ИИ-агентов для автоматизации рутины и создания прототипов аналитических дашбордов, с соблюдением корпоративных стандартов работы с данными. |
| KPI 1 | 80% участников демонстрируют работающий прототип в JustAI на демо-дне Недели 11. |
| KPI 2 | Экономия 15–20% рабочего времени на рутинных задачах участника: журнал времени Недели 0 против журнала Недели 10. |
| KPI 3 | 100% участников сдают план внедрения на 30/60/90 дней, прошедший стресс-тест. |
| Спонсор проекта | Руководитель T&D или бизнес-заказчик с полномочиями по информационной безопасности: утверждает правила зон данных, допуск моделей в JustAI и состав учебных данных. |
| Решения спонсора | Неделя −8: старт разработки. Неделя −2: допуск песочницы JustAI. Неделя 11: участие в демо-дне. |

## Уровень 2. Аналитический

| Параметр | Значение |
| --- | --- |
| Целевая аудитория | Директора департаментов и начальники управлений; 25–70 подчинённых у каждого. |
| Размер группы | 20–25 человек; 5 сетов по 4–5 человек. |
| Входной уровень | Пользователь чат-ассистента или новичок; навыки программирования не требуются. Уровень фиксирует входная диагностика Недели 0. |
| Gap: точка А | Ручной сбор статусов и отчётов; решения по данным, собранным подчинёнными вручную; ИИ используется эпизодически, без правил работы с данными. |
| Gap: точка Б | Руководитель классифицирует данные по зонам, делегирует рутину собственным no-code агентам, работает с прототипом дашборда подразделения. |
| Контекст применения | Рабочее место руководителя; единый интерфейс JustAI; осознанный выбор модели под зону данных задачи. |

**Классификация данных.** Руководитель обучается классифицировать данные
(зелёная, жёлтая, красная зона) и осознанно выбирать модель в интерфейсе
JustAI в зависимости от уровня риска.

| Зона | Данные | Выбор модели в JustAI |
| --- | --- | --- |
| Зелёная | Открытые, синтетические, обезличенные данные | Любая модель, доступная в интерфейсе |
| Жёлтая | Внутренние данные без персональных данных и коммерческой тайны | Модели в контуре компании или российские модели |
| Красная | Персональные данные, коммерческая и банковская тайна | Перевод в жёлтую или зелёную зону маскированием перед обработкой |

### Обоснование онлайн-нагрузки

| Компонент онлайн-недели | А.ч. |
| --- | --- |
| Лекция в записи | 1 |
| Живой практикум или сессия | 2 |
| Задание в JustAI на своих задачах | 2 |
| **Итого** | **5** |

- 5 а.ч. = 3,75 астрономического часа в неделю: менее 10% рабочей недели
  руководителя.
- Референсная программа МФТИ по ИИ в управлении: 6 а.ч. в неделю. Нагрузка
  программы ниже на 1 а.ч. с учётом очных блоков.
- Неделя 0 — 3 а.ч.: орг-сессия, доступы и диагностика без учебного
  контента.

Практика — кейсы в JustAI на задачах участника и синтетических данных.

### Кейсы сетов

| № | Кейс | Компонент JustAI |
| --- | --- | --- |
| 1 | Встреча → протокол → поручения | Агент обработки текста встречи |
| 2 | Контроль поручений и сроков | Агент с триггером по расписанию |
| 3 | База знаний подразделения | RAG по регламентам |
| 4 | Подготовка встречи 1:1 и обратной связи | Агент на обезличенных данных |
| 5 | Дашборд подразделения | Агент-аналитик над выгрузкой задач |

Каждый участник автоматизирует не менее двух собственных рутинных задач; каждый
сет собирает прототип дашборда по своему кейсу.

### Гибкость

- Единый стек JustAI: все кейсы, модели и данные работают в одной
  платформе.
- Адаптация под клиента: замена учебных данных и регламентов в базе знаний,
  подстройка метрик дашборда под функцию подразделения. Платформа при
  адаптации не меняется.
- Задача, которую JustAI не покрывает, заменяется близкой задачей из списка
  кейсов.

## Уровень 4. Технологический и операционный

| Параметр | Значение |
| --- | --- |
| Формат | Blended learning: 3 очных блока по 2 дня, не более 2 очных дней в месяц; 9 онлайн-недель. |
| Календарь | Неделя 1 — месяц 1; Неделя 6 — месяц 2; Неделя 11 — месяц 3. |
| Инфраструктура | Песочница JustAI: 24 рабочих места, шаблоны агентов, база знаний на синтетических регламентах. Корпоративная LMS: записи лекций, задания, журнал времени. |
| Площадка | Помещение Академии. |
| Учебные данные | Синтетические наборы для 5 кейсов с разметкой зон данных. |
