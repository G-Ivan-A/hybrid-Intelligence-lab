# Стратегия вендорских образовательных партнёрств и личного продвижения

> 📦 **Для переноса.** Каталог целиком переносится в приватный репозиторий по
> [плану нового репозитория](new-repository-plan.md). До переноса в нём нет
> коммерческих данных: сделок, цен для конкретных клиентов и контактов.

Каталог отвечает на issue
[#740](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/740) «Стратегия
продвижения комплексная». Гипотеза issue: встраивание ИТ-инструментов вендора
в образовательные программы увеличивает продажи вендора. Стратегия строит на
этой гипотезе консалтинговую услугу для ИТ-компаний и личную стратегию
продвижения специалиста.

   `strategy-probabilities.log`.
