# Программа «ИИ в работе с командой»: ответ на запрос архитектуры MVP

Корпоративная академия · ответ на запрос подразделения · 11 ноября 2026 г.

**Ответ.** Предлагаем шестимесячную программу для 20–25 директоров
департаментов и начальников управлений: онлайн-старт, четыре очных модуля по
два дня раз в месяц, практика между модулями на данных своего подразделения с
поддержкой эксперта и контрольная сессия через 60 дней. Каждый руководитель
выходит с работающим прототипом, двумя рутинными задачами, которые уже
выполняет с ИИ, и планом переноса на 90 дней. Группа целиком получает пять
карт внедрения ИИ в управленческие процессы. Бюджет — в двух вариантах: 10,3
млн ₽ (полный, на несколько потоков) или 3,0 млн ₽ (одна группа, при вкладе
академии натурой); цены без НДС.

## Что получит руководитель

| Ваш ожидаемый результат | Чем программа его обеспечивает |
| --- | --- |
| Знает уровень решения задач, видит сбои по срокам и исполнителям | Реестр поручений из протоколов и переписки и дашборд подразделения по шаблону — их строит каждый участник |
| Понимает возможности команды и люфт для дополнительных задач | Метрики резерва ёмкости и концентрации задач; правила, при которых аналитика касается задач, а не оценки людей |
| Решает на сводной аналитике без дополнительных специалистов | Вопросы к данным на естественном языке и проверка ответа ИИ по исходным данным |
| Снимает рутину встреч, календаря, перформанса | Готовые ИИ-ассистенты, доступные в России, с маскированием персональных данных до отправки в сервис |

## Архитектура

| Этап | Когда | Слой рабочего контура | Результат участника |
| --- | --- | --- | --- |
| М0. Онлайн-старт | месяц 1 | Диагностика, доступы, сеты | Учебный набор данных, сет и кейс |
| М1. ИИ-ассистент из коробки | месяц 2, 2 дня | Встречи, календарь, переписка; безопасность | Два рутинных сценария в работе |
| М2. Поручения и сроки | месяц 3, 2 дня | Реестр поручений, контроль исполнения | Реестр с измеренной точностью ИИ |
| М3. Дашборд подразделения | месяц 4, 2 дня | Сводная картина исполнения и ёмкости | Дашборд, решение по данным |
| М4. Команда, этика, перенос | месяц 5, 2 дня | Правила для команды; демо-день | Защита прототипа, план на 90 дней |
| «+60 дней» | месяц 6, онлайн | Проверка применения | Данные для отчёта об эффекте |

Между модулями — до 4 часов в неделю: практика на своих данных, групповые
онлайн-сессии и индивидуальные консультации эксперта.

**Пять кейсов — пять технологий.** Группа делится на сеты по 4–5 человек.
Каждый сет глубоко ведёт один кейс из вашего запроса и оформляет карту
внедрения по единому шаблону: процесс → технология → сервисы → данные и ИБ →
шаги пилота → метрики → риски. Один сет — один кейс: при 20–25 участниках
работают все пять, при 16–19 — четыре.

| Кейс | Технология |
| --- | --- |
| К1. Встречи | Распознавание речи и языковая модель: протокол, решения |
| К2. Календарь и коммуникации | ИИ-ассистент с доступом к почте и календарю |
| К3. Поручения и сроки | Извлечение поручений, агентные напоминания |
| К4. Перформанс команды | Подготовка встреч один на один и обратной связи |
| К5. Дашборд и сводная аналитика | BI с вопросами к данным на естественном языке |

**Как проверяем результат.** Программа выполнила задачу, если не менее 80%
участников на демо-дне показали прототип кейса на своих данных и две рутинные
задачи с ИИ по рубрике. Оценка — по четырём уровням Киркпатрика: реакция,
навыки, применение по журналу «до/после», прогноз эффекта для бизнеса.

## Бюджет

| | Вариант 1 — полный | Вариант 2 — до 3 млн ₽ |
| --- | --- | --- |
| Цена (без НДС) | Разработка 4,8 млн ₽ + поток 5,5 млн ₽ (группа 20; +180 тыс. ₽ за участника до 25) | 3,0 млн ₽ за разработку и поток до 25 человек |
| Команда | Эксперты с опытом программ для топ-уровня | Практики из технологических компаний МСБ |
| От академии | — | Зал, питание, логистика, ревью ИБ |
| Второй поток | 5,5 млн ₽ | от 1,7 млн ₽ |
| Когда выбрать | Программа на несколько потоков | Проверка на одной группе |

Архитектура в обоих вариантах одна. Вариант 2 экономит на ставках команды,
пилоте и числе учебных наборов, поэтому у него меньше запас прочности.
Лицензии ИИ-сервисов не входят в цену: для 25 учебных аккаунтов на полгода —
около 0,3–0,6 млн ₽.

## Методология

Программа спроектирована от результата: сначала поведение руководителя на
рабочем месте, затем результаты обучения и задания, проверяющие каждый из них,
и только потом содержание модулей. Формат выбран по доказательствам переноса
обучения у руководителей: занятия разнесены во времени, практика идёт на
своих задачах, обратная связь эксперта, обучение в малых группах на
реальных задачах (action learning) и поддержка руководителя участника. Пять
кейсов опираются на обучение через объяснение другим и сравнение примеров.
Основа — {N_REPORTS} исследований и {N_SOURCES} открытых источников, у
каждого вывода указана надёжность; сводка и полный паспорт — по запросу.

Ответ построен по принципу «сначала вывод»: решение и цена — в первом
абзаце, затем аргументы в порядке ваших вопросов, в конце — что требует
вашего решения.

## Ограничения и допущения

- Это кабинетный ответ без уточняющих вопросов: аудитория, политика ИБ и стек
  ИИ-сервисов приняты как допущения и уточняются до старта.
- Ставки — рыночные диапазоны, а не коммерческие предложения. Нефинансовая
  мотивация экспертов (репутация, доступ к аудитории) в бюджете не учтена.
- Кандидаты в команду подобраны по открытым данным ({N_RESEARCHED}
  исследовано, у {N_CHANNEL} есть публичный канал связи), но их согласие и
  ставки не запрашивались. Имена — после согласования.
- Экономия времени руководителя (ориентир 5–15% рутинного времени) —
  гипотеза; программа измеряет её на потоке, а не обещает.
- Прототипы работают на синтетических или обезличенных данных, без
  интеграции с корпоративными системами; внедрение — отдельный трек ИТ.
- Формат пяти кейсов для топ-руководителей проверяется на первом потоке.

## Что нужно от вас

1. Выбрать вариант бюджета и уточнить, включает ли предел 3 млн ₽ НДС.
2. Передать политику ИБ в части ИИ-сервисов и назначить спонсора программы.
3. Подтвердить приоритет кейсов при неполной группе: дашборд → поручения →
   встречи → календарь → перформанс.
