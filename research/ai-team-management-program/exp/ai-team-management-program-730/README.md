# exp: ai-team-management-program-730

Контейнер доказательств для расчёта экономики паспорта проекта
[«ИИ в работе с командой»](../../../../projects/ai-team-management-program/README.md),
issue [#730](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/730).
Результат расчёта используется в
[`economics.md`](../../../../projects/ai-team-management-program/docs/passport/economics.md).

## Зачем отдельная модель

Поток исследования экономики рынка
([`2026-11-10-economics-market-benchmarks.md`](../../2026-11-10-economics-market-benchmarks.md))
считал затраты для рабочей гипотезы «6 очных модулей по 2 дня». Итоговая
архитектура паспорта другая: онлайн-Модуль 0, четыре очных модуля по два дня
раз в месяц, межмодульная работа и онлайн-сессия через 60 дней после
последнего модуля. Поэтому числа отчёта нельзя переносить в паспорт напрямую.
Модель берёт из отчёта только **ставки** (раздел 5.1) и пересчитывает статьи
затрат по итоговой архитектуре. Любое изменение архитектуры (число дней,
сессий, часов куратора) — это правка констант в шапке скрипта и повторный
запуск, а не ручной пересчёт таблиц.

## Что моделируется

- **Разовые затраты на разработку (NRE)** и **затраты на проведение потока
  (Delivery)** — раздельно, в трёх сценариях ставок: минимальном, типичном и
  максимальном.
- **Цена для заказчика**: разработка — единовременно; проведение — базовая
  цена до 20 участников плюс надбавка за участника с 21-го по 25-го. Правило
  минимального счёта «как за 20» закрывает граничный случай ГК-1.
- **Маржинальность** по формуле
  `Маржа, % = (Цена − Себестоимость) / Цена × 100%`. Считается для NRE, для
  проведения при 20, 22 и 25 участниках и для первого потока целиком. Порог
  НФТ-5 — не ниже 30% при группе 20.
- **Чувствительность**: амортизация NRE на K запусков, набор 15–19
  участников, площадка и питание за счёт заказчика, сверка цены за участника
  с рынком.

Вне модели (Д-7 постановки): лицензии ИИ-сервисов, альтернативные издержки
времени участников, интеграции с ERP/CRM. Цены — без НДС; НДС 22% показан
отдельной колонкой.

## Воспроизведение

```bash
cd research/ai-team-management-program/exp/ai-team-management-program-730
python3 economics-model.py > economics-model.log
git diff --exit-code economics-model.log   # пусто — числа паспорта воспроизведены
```

Зависимостей нет, только стандартная библиотека Python 3; сеть не
используется.

Обе проверки выполняются в CI (workflow `validate`): журнал модели сверяется
с новым запуском, а реестр источников — со списками источников отчётов:

```bash
python3 -I build-sources-registry.py --check
```

## Ограничения

Ставки специалистов, кейтеринга и раздатки — гипотезы (○) без открытых
первоисточников. Их нужно заменить коммерческими предложениями до
коммерческого предложения заказчику. Максимальный сценарий показывает, что
при верхних ставках цена 10 млн ₽ за первый поток убыточна: для маржи 30%
нужно ≈ 19,3 млн ₽. Отсюда правило паспорта: сначала договоры с экспертами,
потом цена заказчику.
