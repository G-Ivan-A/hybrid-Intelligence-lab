# Реестр внешних источников проекта «ИИ в работе с командой» (Local Extension)

**Local Extension** к Base Registry Хаба
([`research/external-knowledge/external-sources-registry.md`](../external-knowledge/external-sources-registry.md))
по модели «Base + Local Extension» из
[`docs/rfc/external-knowledge-integration.md`](../../docs/rfc/external-knowledge-integration.md).
Реестр отвечает на вопрос: *какие внешние источники легли в доказательную базу
паспорта проекта
[`projects/ai-team-management-program/`](../../projects/ai-team-management-program/README.md)
и в каком отчёте каждый источник использован*.

## Решения по формату

1. **Почему Local Extension, а не строки в Base Registry.** Источники узкие:
   цены программ ДПО, страницы бизнес-школ, вакансии, тарифы ИИ-сервисов,
   страницы экспертов. По правилу RFC («источник попадает в Base Registry,
   только если он полезен ≥2 проектам») они остаются в проекте. Кандидаты на
   промоцию в Base — мета-анализы по обучению руководителей и переносу
   (Lacerenza 2017, Blume 2010, Clardy 2018, LTEM, Success Case Method): они
   полезны и учебным продуктам Хаба. Промоция — отдельное решение, оно вынесено
   в бэклог.
2. **Локальная нумерация `atm-NNN`.** Сквозная нумерация `ext-NNN` принадлежит
   Base Registry. Если бы проект занимал номера `ext-NNN`, параллельные PR Хаба
   конфликтовали бы с ним за одни и те же номера. Префикс `atm`
   (ai-team-management) делает номера проекта независимыми. При промоции
   источник получает новый `ext-NNN`, а строка здесь — ссылку на него.
3. **Колонки — как в Base Registry.** В колонке «Запись в БЗ» вместо
   инсайта в `external-insights/` стоит ссылка на отчёт и номер источника в
   его списке, например «экономика [21]». Отчёты M3 — это и есть «запись в
   БЗ» для проекта.
4. **Stage.** `research` — страница открыта и прочитана хотя бы в одном
   отчёте; `observation` — источник известен по сниппету поиска, не
   открывался или URL не зафиксирован. Уровень доверия к отдельным
   утверждениям (●/◐/○) живёт в отчётах, не в реестре: один источник может
   подтверждать одно утверждение и не подтверждать другое.
5. **Таблица генерируется, а не пишется руками.** Скрипт
   [`exp/ai-team-management-program-730/build-sources-registry.py`](exp/ai-team-management-program-730/build-sources-registry.py)
   читает разделы «Список источников» семи отчётов, дедуплицирует источники по
   URL, восстанавливает постоянные ссылки по DOI, PMC и PubMed и печатает
   таблицу. После правки списка источников в любом отчёте:
   `python3 research/ai-team-management-program/exp/ai-team-management-program-730/build-sources-registry.py --write`.
6. **Источники без URL не скрываются.** Если отчёт называет источник, но не
   зафиксировал адрес (сниппет поиска, ответ 403, PDF-изображение), строка
   остаётся с пометкой «URL в отчёте не зафиксирован» и стадией
   `observation`. Такой источник не может быть единственной опорой решения в
   паспорте.

Тип источника: `docs` — официальная страница программы, организации или
сервиса; `blog` — СМИ, блог, отраслевой портал; `habr` — Хабр и Хабр Карьера;
`paper` — научная публикация; `standard` — нормативный акт или официальная
налоговая или правовая база; `github` — репозиторий.
