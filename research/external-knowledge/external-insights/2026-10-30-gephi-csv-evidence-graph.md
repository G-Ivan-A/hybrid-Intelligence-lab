# Gephi CSV: явные рёбра вместо списка компаний

Источник `ext-445`: Gephi, [CSV import](https://docs.gephi.org/desktop/User_Manual/Import/CSV_Format/), английский язык, дата публикации не установлена, открыт 30.10.2026. Здесь пересказ технической документации и ссылка; иллюстрации не копируются, отдельная лицензия страницы не установлена.

Наблюдение: импорт различает таблицы узлов и рёбер; Source и Target обязательны для рёбер. Если Id не задан, инструмент назначает его автоматически; существующие узлы можно обновлять по ID. Разделитель, кодировка и типы колонок выбираются при импорте.

Интерпретация для [#709](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/709): список компаний сам по себе не сохраняет отношения. Экспорт должен явно переносить неизменные ID узлов/рёбер и тип отношения. Автоматически назначенные новые ID осложнят связь с журналом свидетельств, поэтому их задаёт пакет. Неизвестные метрики «?» импортируются как текст, без преобразования в 0.

Применение: [контракт и конечная фикстура](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/blob/main/research/reputation-technologies/exp/day1-osint-709/2026-10-30-ten-company-example.md). Граница: выполнен CSV round-trip стандартной библиотекой Python; сам интерфейс Gephi не запускался. Документация не обещает, что импорт проверяет истинность отношений или содержимое наших provenance-карточек.
