# Проверки и источники независимого исследования агентного БА

Родительский отчёт: [исследование #703](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/blob/issue-703-a19ee3f6a30d/research/ba-requirements/2026-10-28-agent-ba-industry-survey.md).
Локальный переход к [тому же отчёту](../../2026-10-28-agent-ba-industry-survey.md)
проверяется валидатором структуры evidence.
Дата замера — 2026-10-28. Это evidence-контейнер, не новый runtime и не
производственный валидатор требований.

## Гипотезы и метод

Проверяются три утверждения отчёта: H1 — структурированный перенос помогает
сохранять проверяемые факты, H2 — решение человека должно быть связано с версией
и полномочиями, H3 — machine-pass не заменяет оценку полноты и точности.
Для каждого утверждения заданы пять отдельных probes с архитектурной,
эксплуатационной, security- и human/governance-перспективами. Это разные
контрпримеры и контроли, не статистически независимая выборка.

`cases.json` — вручную синтезированная политика возврата B2B: восемь исходных
фактов и четыре размеченных варианта результата. Семь лет хранения аудита —
условие вымышленного заказчика, не правовая рекомендация. Правильность gold и
меток не измерялась независимыми экспертами; семантические метки заданы автором.

`measure.py` вычисляет TP/FP/FN и доли, проверяет JSON round-trip, ссылки на
источник, версии, hash, отделение identity от текста approval и повтор доставки
в toy ledger. Корректный hash намеренно пропускает семантическую инверсию:
это отрицательный контроль предела структурной проверки. Identity подаётся
как доверенный вход, authentication и конкурентные транзакции не реализованы.

## Запуск и результат

Из корня репозитория, Python 3, только стандартная библиотека:

```bash
python3 -I research/ba-requirements/exp/agent-ba-industry-703/measure.py --check
```

Запуск ограничен четырьмя вариантами и 15 probes; рекурсии, сети, LLM и SDK нет.
При исходном замере процессу был задан лимит виртуальной памяти 256 MiB
(`ulimit -v 262144` в Bash). В CI выполняется тот же `--check`.

В `results.json` зафиксированы SHA-256 входного файла и результаты: **15/15**
проверок выполнены, first-pass rate **3/4**, false-pass среди прошедших **2/3**,
human escalation rate **1/4**, escalation recall **1/3**. Это проверка арифметики и воспроизводимости
контрпримеров, не измерение качества модели или сравнительный benchmark SDK.
Вердикты H1/H2/H3 и пределы обобщения разобраны в §6 родительского отчёта.

Зафиксированный результат не меняется при обычной проверке. Для намеренного
пересмотра входных случаев или измерителя есть `--write`; полученный diff и
изменения выводов должны быть отдельно проверены:

```bash
python3 -I research/ba-requirements/exp/agent-ba-industry-703/measure.py --write
```

## Источники и границы воспроизводимости

`sources.json` содержит 34 первичных источника, автора/организацию, дату или
версию при наличии, дату доступа, язык, anchor извлечённого вывода и ранее
существовавшие записи общего реестра. Полные тексты источников не копируются.
Динамические страницы документации не являются immutable snapshot.

`repository-snapshot.json` фиксирует десять репозиториев: URL, default branch,
HEAD SHA, дату commit, архивность и SPDX-метаданные GitHub на дату доступа.
Метаданные получены через `gh api repos/OWNER/REPO` и
`gh api 'repos/OWNER/REPO/commits?per_page=1'`. Это не аудит кода. `null`/`NOASSERTION`
не доказывает отсутствие лицензии: для Langfuse прочитан файл LICENSE на SHA,
для iReDev разрешение на OSS reuse осталось неподтверждённым.

Указанный в статье MARE адрес `publicsubmission/MARE-support-material` при
проверке `gh api repos/publicsubmission/MARE-support-material` вернул 404.
Ссылка сохранена в отчёте как неразрешённый anchor; воспроизводимость этого
прототипа и права на код не подтверждены. SAE-кейс изучен только по публичному
abstract; опубликованные QUARE-метрики не воспроизводились. Эти пределы
исключают вывод о production-зрелости рассмотренных решений.
