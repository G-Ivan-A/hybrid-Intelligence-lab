# Логика Дней 1–4: проверка issues #667, #669 и #671

Родительский документ — [RFC: логический каркас Дней 1–4 на 90 минут](../../2026-10-12-rfc-days-1-3-logic.md), задачи — [#667](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/667), [#669](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/669) и [#671](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/671). Скрипт проверяет форму RFC по критериям приёмки issue, а не обучающий эффект. Обучающий эффект проверяется репетицией с секундомером и первым эфиром; см. раздел «Как опровергнуть этот RFC».

`check-rfc-logic.py` проверяет:

- первый раздел документа — «КРИТИЧЕСКАЯ АППЕЛЯЦИЯ» с аппеляцией в форме «АППЕЛЯЦИЯ: Требование …», есть Executive Summary;
- четыре цитаты фаундера из #669 приведены в виде цитат так, как их зафиксировал #671: цитаты 1 и 4 сокращены на «[…]», принцип «Просто в эфире, глубоко в ссылках» записан явно; версия во frontmatter не ниже 0.3;
- в аппеляции есть независимый вердикт «СОГЛАШАЮСЬ / НЕ СОГЛАШАЮСЬ» по GRA как guardrails и решение о структуре кейсов;
- для каждого из четырёх дней 22–26 слайдов: 5 вводных, 15–20 основных, 1–4 финальных, номера подряд;
- у каждого слайда есть поля «Когнитивный сдвиг», «Нарративная связь», «Глубже — в ссылках» (со ссылкой) и «Формат и время»;
- минуты слайдов и резерв дня дают ровно 90, голосований в чате не больше двух, проба промпта ровно одна;
- нет слов «безопасность», «разоблачение», «угроза», «расследование», «ловля» — даже в цитатах, потому что вектор партнёрства первичен; в раскладке дней нет слова «вред», кроме дословной фразы лектора на Дне 3;
- в днях нет формулы GRA, F(t) и H1, рисковой риторики и слова «провокация»; кейс 1 — «Умные холодные продажи» без входящего запроса цен;
- GRA введена на Дне 1 как guardrails, на Дне 1 есть слайд «Как понять, открыта ли сеть к новым поставщикам, используя открытые данные»;
- условие сбора Дня 2 разрешает открытые аккаунты и профили и запрещает скрытые базы;
- проба промпта Дня 3 делает обязательным поиск в Wayback Machine и в открытом вебе;
- на Дне 4 имидж-технологии занимают не меньше 60% эфира (54 минуты), «эклектика / грамотный контраст» объяснена;
- фильтр Дня 3 построен на полезности для встречи, иски кейса 1 на Дне 1 названы маркером активности;
- каждая нарративная связь Дня 4 опирается на результаты Дня 3;
- таблиц нет до раздела «Приложение», в раскладке дней нет промптов изображений;
- ссылки на файлы репозитория и их якоря существуют; нет ссылок на локальные файлы программы, есть ссылка на Техноград;
- отклонённый RFC #665 и папка `presentation-rfc/` помечены `status: rejected`.

В режиме `--self-test` скрипт дополнительно воспроизводит исходную проблему: отклонённый RFC #665 должен не пройти контракт. Кроме того, 33 искусственных повреждения нового RFC должны быть отклонены: от лишнего голосования и слова «вред» в фильтре до формулы на слайде, входящего запроса цен, «провокации» на Дне 4 и доли имиджа ниже 60%. Повреждение, которое не меняет текст, считается не отклонённым.

## Запуск из корня

```bash
python3 -I research/reputation-technologies/exp/rfc-days-logic-667/check-rfc-logic.py --self-test
```

Подсчёт объёма презентаций до и после PR #666, на который ссылается аппеляция:

```bash
for f in 2026-10-07-day1-presentation-653.md 2026-10-30-day2-presentation.md 2026-11-02-day3-presentation.md; do
  for c in 6428ade f3d67da; do printf '%s %s ' "$c" "$f"; git show "$c:research/reputation-technologies/$f" | wc -w; done
done
```

Презентации и сценарии лектора этим контейнером не меняются: issues #667, #669 и #671 запрещают их правку до утверждения RFC фаундером. Пересборка Дня 1 поставлена отдельной задачей — [2026-10-13-day1-rebuild-task-671.md](../../2026-10-13-day1-rebuild-task-671.md).

## Воспроизведение issue #669

`issue-669-before.log` — вывод проверки на версии 0.1 RFC (до #669): нет аппеляции в форме «АППЕЛЯЦИЯ: Требование …», нет принципа «Просто в эфире, глубоко в ссылках», нет цитат фаундера, нет Дня 4, у слайдов нет полей «Когнитивный сдвиг» и «Глубже — в ссылках». `issue-669-after.log` — вывод на версии 0.2: все проверки и 18 повреждений проходят.

## Воспроизведение issue #671

`issue-671-before.log` — вывод проверки версии 0.3 на RFC версии 0.2 (до #671): цитаты 1 и 4 не сокращены и содержат «безопасн», нет вердикта по guardrails и решения о структуре кейсов, кейс 1 построен на входящем запросе цен, на Дне 1 формула и H1, на Днях 3–4 «провокация», нет доли имидж-технологий, этики сбора, фразы лектора и обязательного Wayback Machine. `issue-671-after.log` — вывод на версии 0.3: все проверки и 33 повреждения проходят.
