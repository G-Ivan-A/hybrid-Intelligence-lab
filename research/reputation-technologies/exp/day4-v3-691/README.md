# День 4, Вариант 3: карта гипотез четырёх имидж-технологий и гейт-проверка issue #691

Задача — [#691](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/691). Скрипт проверяет два самостоятельных файла Варианта 3: [презентацию в шаблоне Gamma](../../2026-11-03-day4-presentation-gamma-v3.md) и [сценарий лектора](../../2026-11-03-day4-lecturer-script-v3.md). Оба собраны с нуля только по базовым правилам Gamma из постановки #691 и не ссылаются на предыдущие варианты Дня 4. Насколько удачны сами гипотезы, скрипт не оценивает: это проверяется чтением и репетицией.

| Файл | Что делает |
| --- | --- |
| `check-day4-691.py` | Гейт-проверка двух файлов Варианта 3 и самопроверка на искусственных повреждениях |
| `mutation_reasons_691.py` | Печатает первую ошибку, которую вызывает каждое повреждение самопроверки: видно, что повреждение отклонено по своей причине, а не случайно |
| `issue-691-before.log` | Вывод проверки на `main` до #691 и на первом черновике сценария |
| `issue-691-after.log` | Вывод проверки после #691 |

`check-day4-691.py` проверяет:

- в презентации 6 слайдов, номера подряд; слайды 2–5 — ровно четыре технологии в порядке «Технология: Цвет», «Технология: Форма», «Технология: Стиль», «Технология: Аксессуары», других слайдов «Технология: …» нет; у каждого слайда ровно три поля `[SLIDE_TEXT]`, `[IMAGE_PROMPT]`, `[FOOTER_LINKS]`;
- каждая строка текста слайда начинается с метки, метки идут в порядке Шапка → Надзаголовок → Заголовок → Эпиграф → Вводный абзац → Карточка → Вывод; шапка — «Введение в репутационный инжиниринг · Имиджевые стратегии для действия»; надзаголовок — прописными; заголовок на экране совпадает с заголовком слайда и не длиннее шести слов; вводный абзац — одно или два предложения;
- на каждом слайде технологии карточки идут как Название → Базовый принцип → Вектор Гармонии → Вектор Контраста/Эклектики: `01 · ТЕХНОЛОГИЯ — <название>. Традиционно …` (одно-два предложения), `02 · ВЕКТОР: ГАРМОНИЯ`, `03 · ВЕКТОР: КОНТРАСТ/ЭКЛЕКТИКА`;
- запрет 1: в презентации вне гейт-проверки и во всём сценарии нет терминов GRA — «масса», «дистанция», «полярность», статусов VERIFIED, PARTIAL, CONFLICT и самого «GRA»;
- запрет 2: нет сквозных кейсов курса — «Х», «Д», «С» в кавычках-ёлочках, сети, дистрибьютора, производителя, консервов, оптовых покупателей;
- запрет 3: связки «потому что → поэтому» нет на слайдах; в сценарии она стоит ровно один раз в конце речи к слайдам 1–5 и ведёт к следующему слайду, в речи к слайду 6 и вне речей её нет;
- промпт иллюстрации — английский, начинается с темы и слово в слово содержит базовую фразу постановки: ар-деко, лёгкий Баухаус и Neue Sachlichkeit, контрастный свет, синий и графит, один тонкий акцент, 9:16, без текста, логотипов и искажений; темы идут архитектура → арт → мода, акцент — золото → малахит, второго акцента нет; главный объект — в центре кадра, чтобы кроп 70×168 мм его не срезал; люди 30–50 лет есть только в модной фотографии, без офиса и улыбки;
- подвал — одна строка «Источники: …» с полными ссылками, «(Telegram) @gulienko @qwen-3.7plus @claudeopus-5.5» и «Москва, 10.2026»;
- промпт для генерации в Gamma содержит все пять базовых правил (формат, поля, шрифты и кегли, цвета, фото, инфографика) и не вводит цвета вне них; в таблице фото сторона чередуется слева/справа; шесть пунктов гейт-проверки отмечены `[x]`; раздел «Решения исполнителя в пределах постановки» на месте;
- сценарий: пометки `[СЛАЙД 1]`…`[СЛАЙД 6]` идут подряд, заголовки совпадают с презентацией, каждый слайд — 1,2 минуты, итог тайминга — 7,2 минуты; речь — 150–180 слов, с `[ПАУЗА]`, `[ДЕМОНСТРАЦИЯ ЭКРАНА]` источника из подвала и `[ПЛАН Б ДЛЯ МОЛЧАЛИВОГО ЧАТА]`; в речах есть примеры из финтеха, luxury и deep-tech; ни одна цепочка из восьми слов подряд не повторяет текст слайдов; черновых HTML-комментариев нет;
- в обоих файлах `source` — issue #691; ссылки — полные URL; Вариант 3 ссылается только на свои файлы и не называет предыдущие варианты; файлы и якоря репозитория, на которые ведут ссылки, существуют.

В режиме `--self-test` каждое из искусственных повреждений должно быть отклонено; их число печатает последняя строка вывода. Среди них: пятая технология, удалённый слайд технологии, технологии не по порядку, четвёртое поле, потерянная шапка, строка без метки, вложенный пункт карточки, заголовок длиннее шести слов, три предложения во вводном абзаце, карточки не по порядку, базовый принцип без «Традиционно», термин GRA, статус данных и «масса» в презентации, сеть «Х» и дистрибьютор, мост на слайде, русский или правленый промпт иллюстрации, темы не по очереди, два акцента, человек моложе 30 лет, стоковая улыбка, человек вне модной фотографии, подвал без Telegram или без «Источники:», выдуманный HEX малахита, промпт Gamma без правила, снятая отметка гейта, ссылка на предыдущее обоснование, относительная ссылка, сломанный якорь. Для сценария: потерянная пометка слайда, заголовок не как в презентации, слайд не на 1,2 минуты, неверный итог тайминга, короткая и длинная речь, потерянные метки, речь без моста, второй мост, мост после последнего слайда и вне речей, речь без примера из deep-tech, речь, пересказывающая слайд, сквозной кейс и термин GRA в речи.

## Запуск из корня

```bash
python3 -I research/reputation-technologies/exp/day4-v3-691/check-day4-691.py --self-test
python3 -I research/reputation-technologies/exp/day4-v3-691/mutation_reasons_691.py
```

Ожидаемый вывод первой команды — строки `PASS:` и `PASS: 61 broken fixtures rejected`.

## Воспроизведение issue #691

`issue-691-before.log` — два прогона до готового комплекта. Первый прогон — на `main` до #691: файлов Варианта 3 нет, проверка падает с `file not found` на оба файла. Во втором прогоне готовая презентация лежит рядом с первым черновиком сценария, и проверка находит, что речь к слайду 5 повторяет восемь слов подряд из карточки «Аксессуары», то есть читает экран вслух, а не раскрывает гипотезу.

`issue-691-after.log` — вывод после #691: все проверки проходят, все 61 повреждение самопроверки отклонено.
