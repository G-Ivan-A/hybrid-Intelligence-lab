Контейнер содержит только проверки и обезличенные журналы; JSON диалога и реальные персональные сведения здесь не хранятся.

Локальный родительский отчёт для валидатора evidence: [дизайн пайплайна](../../2026-10-30-day1-osint-pipeline-design.md).

```bash
python3 -I research/reputation-technologies/exp/day1-osint-709/check-pipeline-709.py --self-test
python3 -I research/reputation-technologies/exp/handout-registry-700/check-handout-700.py --self-test
```

`before.log` — запуск нового скрипта на реестре до изменений #709, исходный HEAD `712b9644ba84528012760756f888961b5d0d4945`. Проверка падает из-за отсутствующих 1.0/1.2, внешнего контекста в 1.1/2.1 и недостающих правил. `after.log` — обе команды на обновлённом реестре. Скрипт проверяет четыре самостоятельных блока и отклоняет 77 повреждений: удаление правил, контекста происхождения и границ обработки, возврат зависимости от курса и прежнего расписания.

Это регрессионный контроль текста инструкций, **не** исполнение запросов в потребительских LLM и **не** доказательство отсутствия галлюцинаций. Удаление целевой фразы проверяется с учётом всех её вхождений; случайная оставшаяся копия не маскирует повреждение. Старый гейт #700 сохраняет проверки остальных материалов, изображений и презентаций; только обязательный Course/Day/анкета для новых блоков заменён новым, более подходящим контрактом.

15 синтетических сценариев T01–T15 и пороги опровержения H1–H3 записаны в дизайне рядом с результатом экспертного прохода. Входы конечны (максимум 20 компаний/перепечаток); сетевой поиск и обращение к модельному API в скрипте отсутствуют. Для реальной проверки чата используйте протокол из дизайна и явно отделяйте наблюдённый ответ модели от ожидаемого результата.
