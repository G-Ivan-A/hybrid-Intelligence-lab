`before.log` — исходный запуск гейта на реестре до #709, HEAD `712b9644ba84528012760756f888961b5d0d4945`: отсутствовали 1.0/1.2, автономность и safeguards. `feedback-before.log` — расширенная проверка на f631520 до исправления трёх новых комментариев PR #710: 26 ошибок основного маршрута, графа, метрик и отраслевого поиска без памяти. `after.log` — все три команды после исправления. Структурный гейт четырёх автономных промптов отклоняет 102 удаления/повреждения правил; старый гейт #700 — 47 повреждений остальных материалов и расписания. Удаление фразы проверяется с учётом всех вхождений, чтобы случайная оставшаяся копия не скрывала повреждение.

[Десять компаний: вход, сохранённый результат и экспорт](2026-10-30-ten-company-example.md) — конечный проход автора изменений по правилам 1.0 → 1.1 → 2.1 с источником АРПП. Это не стенограмма потребительской LLM. Все 40 утверждений PARTIAL; реальный статус, покупательский интерес и личности не установлены. CSV-блоки — опциональный машинный экспорт, обычный ответ слушателю остаётся коротким outline с карточками. `check-graph-709.py` читает эти блоки, проверяет ссылки, полный охват C01–C10 и сохранение всех значений при CSV round-trip. Двенадцать отрицательных мутаций проверяют оборванные ссылки, дубликат, потерю компании, неизвестное вместо 0/cold/+1, необоснованный VERIFIED, четвёртый маркер и исчезнувшее основание. Фильтр фактических VERIFIED отношений оставляет 0 из 30 рёбер. Синтетический положительный контроль допускает одно ребро после добавления даты/ручной проверки, а дополнительное PARTIAL-утверждение у того же ребра снова исключает его; сохранённый пример не изменяется. Валидатор предназначен для этой конечной фикстуры с неизвестными метриками, не является общим верификатором произвольного OSINT-графа.

T01–T15/H1–H3 — экспертный синтетический проход в дизайне; T16–T20/H4 — исполняемая графовая проверка. Входы конечны (максимум 20 компаний/перепечаток), скрипты используют стандартную библиотеку, не сеть или модельный API. Не проверяют поведение всех чатов, отсутствие галлюцинаций или интерфейс Gephi. Для реального сервиса используйте протокол из дизайна, сохраняйте модель/дату/веб-режим/исходный ответ и отделяйте наблюдение от ожидаемого результата. Предложение B-233 остаётся предложением измерить конкретные сервисы; оно не заменяет текущие результаты.
