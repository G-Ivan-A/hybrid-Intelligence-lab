# Цитаты курса по дням 1–4 в разметке ALCE: построение и проверка, issue #711

[Задача](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/711). Результат — один файл: [список цитат по дням 1–4](../../2026-11-01-course-quotes-days-1-4-alce.md). У каждой цитаты есть интерпретация для репутационных технологий, полные имена авторов, дата, полное название источника без сокращений и ссылка; все `[n]` сводятся к списку источников в конце файла.

Основа списка — каталог цитат [#650](../../2026-09-30-course-sources-and-presentations-650.md): в списке все его 232 цитаты из источников со статусом VERIFIED. К ним добавлены 41 цитата из материалов курса, которых в каталоге нет: Г12, М1–М7, Simini и Gentner, Т3–Т5 и эпиграфы колоды дня 4 (v5). Что не вошло и почему — в разделах «Границы списка» и «Пробелы и решения» самого файла.

| Файл | Что делает |
| --- | --- |
| `extract_650.py` | Извлекает цитаты каталога #650 с номерами строк, переводами и местом в источнике |
| `inventory-650.json` | Результат `extract_650.py`: опись цитат каталога, по которой проверяется полнота |
| `quotes_711_data.py` | Данные об источниках: полные имена, даты, полные названия, ссылки, статусы, распределение по дням, дополнительные цитаты и правки |
| `names-evidence-711.json` | Откуда взяты полные имена и отчества российских авторов: адрес страницы или DOI и найденная строка |
| `expand_titles_711.py` | Разовая правка названий в `quotes_711_data.py`: убирает инициалы авторов в начале и раскрывает сокращения (pp., No., №, С., с., ПАО); уже применена, повторный запуск ничего не меняет |
| `interpretations-711.json` | Интерпретации для репутационных технологий по ключу цитаты; написаны по заметкам «Для курса» и «Поддержка и ограничения» каталога и по обоснованиям дней |
| `source-excerpts-711.txt` | Оригиналы цитат, которые в материалах курса даны только в переводе, и цитаты из аннотаций издательств, с адресом, по которому они сверены |
| `build_quotes_711.py` | Строит файл списка; `--check` сравнивает с файлом на диске без записи; `--worklist PATH` пишет рабочий список для интерпретаций |
| `check-quotes-711.py` | Гейт-проверка списка; читает сам Markdown-файл и от построителя не зависит; `--self-test` проверяет также, что все искусственные повреждения отклонены |
| `mutation_reasons_711.py` | Печатает первую ошибку, которую вызывает каждое повреждение самопроверки |
| `issue-711-before.log` | Вывод проверки до #711 и на черновике без интерпретаций |
| `issue-711-after.log` | Вывод проверки, причины отклонения повреждений и `build --check` после #711 |

`check-quotes-711.py` проверяет:

- frontmatter без `ai-generated`, `source` — issue #711; во введении объяснена разметка ALCE; разделы «День 1» … «День 4», «Границы списка», «Пробелы и решения», «Список источников (ALCE)» по порядку;
- у каждой цитаты есть поля задачи: цитата, интерпретация, авторы, дата, источник, ссылка, а также место в источнике, статус проверки и строка в репозитории; интерпретация не пустая и помечена номером источника;
- цитата дословно стоит в строке репозитория, на которую ведёт ссылка; перевод из репозитория дословно стоит в своей строке; у цитаты не на русском языке есть перевод; оригинал с полем «Сверка с источником» дословно есть в `source-excerpts-711.txt`; эпиграф слайда N стоит в своей строке колоды дня 4;
- полное название источника не начинается со списка авторов в инициалах и не содержит библиографических сокращений (pp., No., Vol., №, С., с., ПАО, СПб, М.:, Т., Вып.); в поле «Место в источнике» нет сокращений p., с., Ch., Sec., п., прим., et al. и статуса проверки;
- ALCE: каждый `[n]` есть в списке источников, каждая запись списка используется, один ключ источника на номер, номера идут в порядке первого упоминания; у записи полная ссылка `https://` и статус VERIFIED;
- полнота: все цитаты описи `extract_650.py` есть в списке, а всего цитат — опись плюс 41 дополнительная.

## Запуск из корня

```bash
python3 -I research/reputation-technologies/exp/quotes-711/check-quotes-711.py --self-test
python3 -I research/reputation-technologies/exp/quotes-711/mutation_reasons_711.py
python3 -I research/reputation-technologies/exp/quotes-711/build_quotes_711.py --check
```

Ожидаемый вывод первой команды — строка `PASS:` с числом цитат и `PASS: 24 broken fixtures rejected`. Третья команда подтверждает, что файл списка совпадает с тем, что строит `build_quotes_711.py` из данных; после правки данных запустите построитель без флагов, и он перепишет файл.

Скрипты используют только стандартную библиотеку и не обращаются к сети. Сверку оригиналов с внешними источниками скрипты не повторяют: адреса, по которым она сделана, записаны в `source-excerpts-711.txt`.

## Воспроизведение issue #711

`issue-711-before.log` — два прогона. Первый — до #711, на коммите `32b5fa5`: файла списка нет, проверка падает с `file not found`. Второй — на черновике, в котором уже есть все цитаты, источники и ссылки ALCE, но нет интерпретаций: проверка отклоняет каждую из 273 цитат.

`issue-711-after.log` — вывод после #711: все проверки проходят, все 24 повреждения самопроверки отклонены, у каждого своя причина, и файл совпадает с выводом построителя.
