# День 4, промпты изображений v5 (Couturier Constructor): гейт-проверка issue #699

Задача — [#699](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/699). [Файл-конструктор](../../2026-11-03-day4-image-prompts-v5-couturier-constructor.md) даёт к каждому из 27 слайдов [колоды v5](../../2026-11-03-day4-presentation-gamma-v5.md) Вариант А «Гармония» и Вариант Б «Эклектика», каждый на `[EN]` и `[RU]`: 108 промптов. Скрипт проверяет форму файла и обязательные элементы §5–§7 issue в каждом промпте. Насколько красивы получатся кадры, он не оценивает: это проверяется генерацией и глазом.

| Файл | Что делает |
| --- | --- |
| `check-day4-image-prompts-699.py` | Гейт-проверка файла промптов по карте распределения и самопроверка на искусственных повреждениях |
| `mutation_reasons_699.py` | Печатает первую ошибку, которую вызывает каждое повреждение самопроверки: видно, что повреждение отклонено по своей причине, а не случайно |
| `issue-699-before.log` | Вывод проверки до #699: файла промптов нет |
| `issue-699-after.log` | Вывод проверки и причины отклонения повреждений после #699 |

`check-day4-image-prompts-699.py` проверяет:

- `source` файла — issue #699, заголовок дословно из §6; 27 разделов `## Слайд N.` с названиями, совпадающими с заголовками колоды v5, каждый кончается `---`;
- карта распределения: 54 строки 1А…27Б; каждый из 26 домов §4 стоит ровно на двух слайдах со страной бренда; город — не больше двух раз и не в обоих вариантах одного слайда; у соседних вариантов разные культурная зона, тип субъекта (W, M, MF, WW, MM), движение и тип арт-объекта; трёх европейских городов подряд нет; движение пары не дано одной модели; три разных базовых цвета на вариант;
- на каждом слайде строка «Кутюрье-гейт» называет оба дома с дизайнером и страной из карты, «Интерпретация» — ровно одно предложение, заголовки вариантов — «Гармония» и «Эклектика» с домом и дизайнером;
- каждый промпт начинается с *Tall narrow vertical banner photograph* / *Высокий вертикальный баннер* и кончается хвостом §6 своего варианта с городом карты (*Always recognisable Art Deco in Paris.* / *Всегда узнаваемое Ар-Деко в Париже.*, *Surreal-meets-classical eclecticism.* / *Сюрреалистичная эклектика.*);
- в каждом промпте — пропорции словами и каркас §5.1 (одна непрерывная сцена, без панелей и рамок, high-key дневной свет, Ар-Деко), возраст 30–50, резкий фокус и серьёзное лицо, город карты (`Real Paris,` / `Париж (Paris)`), дом, сезон, тип субъекта;
- HEX-коды промпта — ровно два цвета одежды, цвет объекта и золото #B89B5E; цвета одежды и золото стоят до слов «art object» / «арт-объект», цвет объекта — после;
- умеренная разнообразная массовка в боке; не меньше трёх маркеров ДНК дома из §5.3; запрещённых слов §7 и их русских соответствий нет, как и простых тел, статуй и манекенов; *draping*, *pleats* и русские пары — только в предложении с именем дома; не больше 4000 знаков (лимит DALL-E 3), не меньше 280 слов в `[EN]` и 240 в `[RU]`;
- раздел «Гейт-проверка» — не меньше шести пунктов `[x]` и ни одного пустого; раздел «Отклонения от постановки» есть.

В режиме `--self-test` каждое из искусственных повреждений должно быть отклонено; их число печатает последняя строка вывода, а `mutation_reasons_699.py` показывает, какой проверкой отклонено каждое.

## Запуск из корня

```bash
python3 -I research/reputation-technologies/exp/day4-image-prompts-v5-699/check-day4-image-prompts-699.py --self-test
python3 -I research/reputation-technologies/exp/day4-image-prompts-v5-699/mutation_reasons_699.py
```

Ожидаемый вывод первой команды — строки `PASS:` и `PASS: 44 broken fixtures rejected`.

## Воспроизведение issue #699

`issue-699-before.log` — прогон до готового файла, на коммите `d217a08`: файла промптов нет, проверка падает с `is missing`.

`issue-699-after.log` — вывод после #699: все проверки проходят, все 44 повреждения самопроверки отклонены, и у каждого своя причина.
