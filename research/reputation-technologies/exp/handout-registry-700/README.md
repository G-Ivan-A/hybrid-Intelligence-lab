# Раздаточные материалы Дней 1–4 (Master Prompt Registry): гейт-проверка issue #700

Задача — [#700](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/700). [Файл раздаточных материалов](../../2026-10-24-handout-materials-master-prompt-registry-days-1-4.md) собирает в один документ всё, что лектор отправляет слушателям в Дни 1–4: расписание выдачи по слайдам, восемь шаблонов промптов (#709 добавляет 1.0/1.2 и обновляет 1.1/2.1), примеры с разбором ошибок, домашние задания и материалы упражнений. Скрипт проверяет форму файла и обязательные элементы §4–§7 issue. Насколько хорошо модель ответит по шаблону, он не оценивает: это проверяется прогоном шаблона в LLM.

| Файл | Что делает |
| --- | --- |
| `check-handout-700.py` | Гейт-проверка файла раздаточных материалов и самопроверка на искусственных повреждениях |
| `mutation_reasons_700.py` | Печатает первую ошибку, которую вызывает каждое повреждение самопроверки: видно, что повреждение отклонено по своей причине, а не случайно |
| `issue-700-before.log` | Вывод проверки до #700: файла раздаточных материалов нет |
| `issue-700-after.log` | Вывод проверки и причины отклонения повреждений после #700 |

`check-handout-700.py` проверяет:

- `source` файла — issue #700, без `ai-generated`; заголовок говорит, что это раздаточные материалы; есть «Как пользоваться» и «Когда что раздавать» со строками по всем четырём дням и слайдам выдачи;
- заголовки `## День N. Тема:` для Дней 1–4 совпадают с темой из строки «Шапка» каждой колоды; задачи 1.0, 1.1, 1.2, 2.1, 2.2, 3.1, 4.1, 4.2 идут по порядку;
- в каждой задаче — «**Цель:** Сгенерировать…», инструменты (Claude, GPT, Gemini, GigaChat; для 4.2 — Midjourney, DALL-E, Nano Banana), блоки 📋, 💡 с «Вход» и «Ожидаемый выход», 🔁 «Разбор ошибок» и ⚠️ с тремя пунктами комментария; промпт в блоке ```text с заголовками # ROLE → # CONTEXT → # INPUT DATA → # TASK → # OUTPUT FORMAT, ролью «You are a Senior…», строками контекста дня и полями `[FIELD]` для замены для прежних блоков 2.2/3.1/4.1; новые автономные 1.0/1.1/1.2/2.1 проверяются по контракту #709, без обязательного Course/Day/анкеты;
- задача 2.2 (аудит цифрового следа, §6) — веерный поиск по VK, LinkedIn, Facebook, Instagram, Telegram, Habr, VC.ru, правила «не только академические базы» и `Gap`, пример с карточкой книги на LiveLib;
- задача 4.1 — четыре оси и векторы Гармония/Эклектика; задача 4.2 — пять переменных, инструкция о 26 домах дословно, каркас кадра (около 1 к 2,4, high-key, золото #B89B5E), четыре жёстких ограничения в чек-листе, ни одного запрещённого или общего слова из проверки #699, не больше 4000 знаков; таблица 26 домов, у каждого не меньше трёх маркеров ДНК из проверки #699;
- домашние задания Дней 1–4; якорные ссылки ведут на заголовки, остальные ссылки абсолютные, ссылки на репозиторий ведут на существующие файлы, колода Дня 4 — последняя версия (v5);
- отклонения сформулированы как «Я предлагаю скорректировать …, потому что вариант … лучше подходит для автономного использования слушателем»; раздел «Gaps» фиксирует недоступный `2.txt`.

В режиме `--self-test` каждое из искусственных повреждений должно быть отклонено; их число печатает последняя строка вывода, а `mutation_reasons_700.py` показывает, какой проверкой отклонено каждое.

## Запуск из корня

```bash
python3 -I research/reputation-technologies/exp/handout-registry-700/check-handout-700.py --self-test
python3 -I research/reputation-technologies/exp/handout-registry-700/mutation_reasons_700.py
```

Ожидаемый вывод первой команды — строки `PASS:` и `PASS: 47 broken fixtures rejected`.

## Воспроизведение issue #700

`issue-700-before.log` — прогон до готового файла, на коммите `b81331d`: файла раздаточных материалов нет, проверка падает с `is missing`.

`issue-700-after.log` — вывод после #700: все проверки проходят, все 47 повреждений самопроверки отклонены, и у каждого своя причина.
