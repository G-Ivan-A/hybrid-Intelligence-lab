# exp: ops-task-strategy-461

Evidence container for the research report
[`../../2026-07-31-ops-task-strategy-validation.md`](../../2026-07-31-ops-task-strategy-validation.md),
issue [#461](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/issues/461).

## Гипотеза

Введение «точки входа в репозиторий» как индекса с контрактами решений
(правила проверки задачи, при необходимости эскалация) стабилизирует поведение
агента и снижает количество ошибок, не подавляя полезную инициативу.

Проверка разложена на два независимых вопроса, потому что гипотеза объединяет
два разных утверждения: **работает ли индекс как носитель правил** и **работают
ли сами контракты решений**. Ответы оказались разными.

## Метод

Всё измеряется по реальным артефактам трёх репозиториев, без синтетических
задач: единица наблюдения — пара «issue → PR», исход размечается механически по
диффу и состоянию PR, признаки постановки — регулярными выражениями по телу
issue. Скрипты используют только стандартную библиотеку Python; статистика
детерминирована (seed 20260731, 20 000 перестановок), поэтому числа отчёта
воспроизводятся из зафиксированного здесь корпуса.

| Скрипт | Направление | Что делает | Выход |
| --- | --- | --- | --- |
| `collect-evidence.py` | 1 | Забирает PR и issue трёх репозиториев через `gh`, размечает исход PR и признаки постановки | `corpus-metrics.json`, `collect-evidence.log` |
| `analyze-outcomes.py` | 1 | Точный тест Фишера, перестановочные тесты, Спирмен, интервалы Уилсона, оценка мощности | `analysis-outcomes.json`, `analyze-outcomes.log` |
| `experiment-references.py` | 2 | Разрешает пути, названные в issue, против дерева репозитория **на дату постановки**, с контролем на месяц | `experiment-references.json`, `experiment-references.log` |
| `experiment-closure.py` | 2 / 3 | Обходит граф Markdown-ссылок от кандидатов на точку входа, считает замыкание и бюджет контекста | `experiment-closure.json`, `experiment-closure.log` |
| `model-contract-index.py` | 3 | Реализует контракты как исполнимую проверку и сравнивает два размещения: гейт по тексту против постусловия на диффе | `model-contract-index.json`, `model-contract-index.log` |

### Разделение признаков постановки

Ключевое методическое решение: признаки разделены на **детализацию** (goal,
context, dod, sources, steps, constraints, operating_mode, validation — 0–8) и
**контракты решений** (verification_rule, escalation_rule, autonomy_rule,
nonempty_rule — 0–4). Агрегированная «детализация» смешивает их и скрывает
главный результат: две группы ведут себя по-разному.

### Известные ограничения измерения

- Формы коммитов запрашиваются только для непродуктивных PR (экономия вызовов
  API), поэтому отсутствие `commit_count` или `has_revert` в записи **не следует
  читать как `false`**.
- `experiment-references.py` измеряет только Хаб: разрешение путей на дату
  постановки требует полной локальной истории git.
- Ссылки, первый сегмент которых не является каталогом верхнего уровня Хаба,
  считаются вне области (проза со слэшами, пути соседних репозиториев) и не
  засчитываются как неразрешимые.
- Оценка токенов в `experiment-closure.py` — байты / 3.2, порядок величины, а не
  измерение токенизатором.

## Результаты

| Тест | Результат |
| --- | --- |
| Детализация против исхода | не различает: 4.40 против 4.06, p = 0.6478 |
| Детализация против объёма работы | слабая связь: ρ = 0.1416, p = 0.0035, n = 456 |
| Контракты в практике | 426 из 475 постановок не содержат ни одного |
| Разрешимость ссылок, июнь, внутри месяца | детальные протухают сильнее: 0.341 против 0.161, p = 0.001 |
| Замыкание точки входа | 232 файла, ~1.6M токенов — одинаково для всех пяти кандидатов |
| Гейт по формулировке | precision 0.022, ~46 прерываний человека на один пойманный отказ |
| Постусловие на диффе | 4–6 срабатываний, 0 ложных при мерже, 60% покрытия непродуктивных PR |
| Естественный эксперимент #453 → #455 | детализация 8→4, контракты 2→4, исход: пустой мерж → 45 добавлений |

## Воспроизведение

```bash
python3 collect-evidence.py          # требует gh auth
python3 analyze-outcomes.py
python3 experiment-references.py
python3 experiment-closure.py
python3 model-contract-index.py
```

`collect-evidence.py` кэширует ответы `gh` вне репозитория
(`/tmp/ops-task-strategy-461-cache`) и поддерживает `--offline` для повторного
прогона по кэшу. Остальные скрипты работают по зафиксированному
`corpus-metrics.json` и сети не требуют.
